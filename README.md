# Lillo

Dois apps do Lillo neste repositório:

| Pasta | Descrição |
|-------|-----------|
| `agenda-web/` | Site Next.js (painel + agendamento público) |
| `agenda-mobile/` | App Expo (React Native) |

Cada um tem o próprio `package.json` — instale dependências **dentro da pasta** (`npm install`). Não há workspace na raiz.

## Comandos rápidos

```bash
cd agenda-web && npm run dev
cd agenda-mobile && npm start
```
